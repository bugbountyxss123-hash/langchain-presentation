01

ما هو LangChain؟

إطار عمل يحوّل نموذج اللغة إلى تطبيق حقيقي.

✦

LangChain مكتبة بايثون (وTypeScript) توفّر لبنات بناء جاهزة لربط نماذج اللغة بالمطالبات، والذاكرة، ومصادر البيانات، والأدوات الخارجية — وتتيح تركيبها في سير عمل واحد.

◇

واجهة موحّدة

نفس الكود مع OpenAI أو Anthropic أو نموذج محلي — غيّر النموذج فقط.

⛓

تركيب المكوّنات

بنى صغيرة قابلة للربط بعلامة | لتصنيع سلسلة كاملة.

⌁

بيانات وأدوات

اربط المستندات وقواعد البيانات وواجهات API بالنموذج بسهولة.

تنبيه: LangChain ليس نموذج ذكاء اصطناعي؛ هو الإطار الذي ينظّم عمل النموذج داخل تطبيقك.

03

أول سلسلة: Prompt → Model → Parser

LCEL يسمح لك بتركيب المكوّنات بعلامة الأنبوب |.

main.py
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "أنت معلّم بايثون مختصر وودود."),
    ("human", "اشرح لي: {topic}"),
])

chain = prompt | model | StrOutputParser()

print(chain.invoke({"topic": "القوائم في بايثون"}))
# أو بثّ الإجابة كما تُكتب:
for piece in chain.stream({"topic": "الدوال"}):
    print(piece, end="", flush=True)

prompt

يحوّل المدخلات إلى رسائل جاهزة للنموذج.

model

يرسل الرسائل ويُعيد إجابة من نوع AIMessage.

parser

يحوّل الإجابة إلى نص عادي str.

04

الذاكرة والمحادثة

النموذج لا يتذكّر شيئاً بين الطلبات — أنت من يرسل السجل مع كل طلب.

messages.py
from langchain_core.messages import (
    SystemMessage, HumanMessage, AIMessage
)

history = [SystemMessage(content="أنت مساعد عربي مختصر.")]

while True:
    text = input("أنت: ")
    if text == "خروج": break
    history.append(HumanMessage(content=text))

    reply = model.invoke(history).content
    print("المساعد:", reply)

    history.append(AIMessage(content=reply))

SystemMessage

تحديد الدور والسلوك — يُرسل مرة واحدة في البداية.

HumanMessage

رسالة المستخدم الحالية.

AIMessage

رد النموذج الذي تضيفه إلى السجل.

تلميح

للمحادثات الطويلة: لخّص السجل أو احتفظ بآخر N من الرسائل.

في التطبيقات الكبيرة استخدم RunnableWithMessageHistory لحفظ السجل في Redis أو قاعدة بيانات بدلاً من الذاكرة المحلية.
05

RAG — أجب من مستنداتك

Retrieval Augmented Generation: استرجع المادة ثم اطلب الإجابة.

مستندات→تقسيم Chunks→Embeddings→قاعدة متجهة→استرجاع→نموذج
rag.py
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_core.runnables import RunnablePassthrough

docs = TextLoader("notes.txt").read()
chunks = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=50
).split_documents(docs)

db = FAISS.from_documents(chunks, OpenAIEmbeddings())
retriever = db.as_retriever(search_kwargs={"k": 3})

rag = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt          # مطالبة تحتوي على {context} و {question}
    | model
    | StrOutputParser()
)

print(rag.invoke("ما شروط التراجع في المادة الثالثة؟"))
قاعدة بسيطة: لا تطلب من النموذج الحفظ — أعطِه المادة الصحيحة في لحظة السؤال.
06

الأدوات والوكلاء (Agents)

الوكيل يقرر متى يستدعي أداة، ويكرر المحاولة حتى يصل لإجابة.

agent.py
from langchain_core.tools import tool
from langchain.agents import create_agent

@tool
def get_weather(city: str) -> str:
    """إرجاع حالة الطقس الحالية لمدينة معينة."""
    return f"الطقس في {city}: مشمس 24°C"

agent = create_agent(
    model="gpt-4o-mini",
    tools=[get_weather],
    system_prompt="أجب بالعربية، واستخدم الأدوات عند الحاجة.",
)

result = agent.invoke({
    "messages": [{"role": "user", "content": "طقس الرياض؟"}]
})
print(result["messages"][-1].content)
1 يفهم السؤال ويخطّط
2 يختار الأداة المناسبة
3 ينفّذها ويقرأ النتيجة
4 يكرّر أو يجيب نهائياً
هذه دورة ReAct: تفكير → فعل → ملاحظة. في الإصدارات الأقدم من LangChain استخدم create_react_agent أو AgentExecutor.
07

مخرجات منظّمة بـ Pydantic

احصل على كائنات بايثون صالحة للبرمجة بدلاً من نص حر.

structured.py
from pydantic import BaseModel, Field

class Recipe(BaseModel):
    name: str
    minutes: int
    ingredients: list[str] = Field(
        description="قائمة المكوّنات بالعربية"
    )

structured = model.with_structured_output(Recipe)

recipe = structured.invoke("وصفة بيض سريعة")
print(recipe.name, recipe.minutes)
print(recipe.ingredients)  # list[str] حقيقي

لماذا مهم؟

تتجنّب تحليل النص يدوياً وتضمن أن الشكل مطابق لتوقعات برنامجك.

أين يُستخدم؟

استخراج بيانات من فواتير، تصنيف تذاكر الدعم، وملء نماذج تلقائياً.

فعّل التتبّع أثناء التطوير: LANGCHAIN_TRACING_V2=true و LANGCHAIN_API_KEY=... لترى كل خطوة في LangSmith.

09

قوالب المطالبات المتقدمة

الآن ننتقل للمستوى المتقدم: أمثلة قليلة (Few-shot) وقوالب قابلة لإعادة الاستخدام.

prompts.py
from langchain_core.prompts import (
    ChatPromptTemplate,
    FewShotChatMessagePromptTemplate,
)

examples = [
    {"input": "قائمة", "output": "قائمة: بيانات مرتبة بالترتيب."},
    {"input": "دالة", "output": "دالة: كتلة قابلة لإعادة الاستخدام."},
]
example_prompt = ChatPromptTemplate.from_messages([
    ("human", "{input}"), ("ai", "{output}"),
])
few_shot = FewShotChatMessagePromptTemplate(
    example_prompt=example_prompt, examples=examples
)
prompt = ChatPromptTemplate.from_messages([
    ("system", "أنت معلّم مختصر. ابدأ بكلمة المفهوم."),
    few_shot,
    ("human", "اشرح: {topic}"),
])

Few-shot

أمثلة داخل المطالبة تحسّن الشكل والدقة دون تدريب.

MessagesPlaceholder

مكان لإدراج سجل المحادثة ديناميكياً داخل القالب.

partial_variables

ثبّت بعض المتغيرات مسبقاً مثل التاريخ أو اسم المستخدم.

قابلية التركيب

القالب نفسه يعمل مع أي نموذج دردشة لاحقاً.

ابدأ بمثال أو مثالين فقط — زيادة الأمثلة ترفع الثمن وتطيل الإجابة دون فائدة كبيرة.

11

بدائل النماذج والتوجيه الذكي

لا تعتمد على مزوّد واحد: بديل عند الفشل، ونموذج مناسب لكل مهمة.

models.py
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic
from langchain_core.runnables import RunnableBranch
from langchain_core.output_parsers import StrOutputParser

cheap = ChatOpenAI(model="gpt-4o-mini", temperature=0)
strong = ChatAnthropic(model="claude-3-5-haiku-latest")

# بديل تلقائي عند تعذّر الوصول أو تجاوز الحد
resilient = cheap.with_fallbacks([strong])

# توجيه حسب نوع المهمة
router = RunnableBranch(
    (lambda x: x["hard"], strong),
    cheap,  # الفرع الافتراضي
)
chain = router | StrOutputParser()
print(chain.invoke({"hard": False, "question": "لخّص هذا النص"}))

موثوقية أعلى

with_fallbacks ينقذ الطلب عند تعطل المزوّد أو نفاد الرصيد.

تكلفة أقل

وجّه المهام البسيطة لنموذج رخيص والمعقدة لنموذج أقوى.

سهولة التبديل

واجهة LangChain الموحّدة تجعل التجربة بين النماذج سطراً واحداً.

12

جودة RAG تبدأ من التقسيم

حجم القطعة والبيانات الوصفية يحددان ما يسترجعه النظام.

chunks.py
from langchain_text_splitters import (
    RecursiveCharacterTextSplitter
)

splitter = RecursiveCharacterTextSplitter(
    chunk_size=450,
    chunk_overlap=80,   # ~10-20% من الحجم
    add_start_index=True,
)
chunks = splitter.split_documents(docs)

for c in chunks:
    c.metadata["year"] = 2025
    c.metadata["source"] = c.metadata.get("source", "")

db = FAISS.from_documents(chunks, OpenAIEmbeddings())
retriever = db.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 4, "fetch_k": 12,
                   "filter": {"year": 2025}},
)

الحجم

300–600 حرف نقطة بداية جيدة للمستندات النصية.

التداخل

تداخل 10–20% يمنع فقدان المعنى عند الحدود.

MMR

يقلّل تكرار المقاطع المتشابهة في نتائج الاسترجاع.

البيانات الوصفية

سنة، قسم، مصدر — استخدمها لتصفية النتائج قبل إرسالها.

أضف source إلى الإجابة ليتمكن المستخدم من التحقق من المرجع.
13

البحث الهجين + إعادة الترتيب

دمج الكلمات المفتاحية بالمعنى الدلالي، ثم ترتيب النتائج بذكاء.

hybrid.py
from langchain.retrievers import EnsembleRetriever
from langchain_community.retrievers import BM25Retriever
from langchain_community.cross_encoders import HuggingFaceCrossEncoder
from langchain.retrievers.document_compressors import CrossEncoderReranker
from langchain.retrievers import ContextualCompressionRetriever

bm25 = BM25Retriever.from_documents(chunks); bm25.k = 5
dense = db.as_retriever(search_kwargs={"k": 5})
hybrid = EnsembleRetriever(
    retrievers=[bm25, dense], weights=[0.4, 0.6]
)

reranker = CrossEncoderReranker(
    model=HuggingFaceCrossEncoder(
        model_name="BAAI/bge-reranker-base"),
    top_n=3,
)
retriever = ContextualCompressionRetriever(
    base_compressor=reranker, base_retriever=hybrid
)

BM25

ممتاز للأسماء والأرقام والكلمات الدقيقة.

المتجهات

يفهم المعنى حتى لو اختلفت الصياغة.

Reranker

نموذج صغير يعيد ترتيب أفضل النتائج قبل إرسالها للنموذج الكبير.

14

الدفعات والتنفيذ غير المتزامن

عند معالجة مئات المدخلات: أرسلها دفعة واحدة وتحكّم بالتوازي.

batch.py
inputs = [{"topic": t} for t in topics]

# دفعة متسلسلة
results = chain.batch(inputs)

# دفعة متوازية بحد أقصى 5 طلبات
results = chain.batch(
    inputs,
    config={"max_concurrency": 5},
)

# نسخة غير متزامنة (مناسبة لـ FastAPI)
import asyncio
results = await chain.abatch(
    inputs, config={"max_concurrency": 5}
)

زمن أقل

التوازي يختصر زمن الانتظار عند كثرة الطلبات المستقلة.

احترم الحدود

max_concurrency يحميك من أخطاء Rate Limit.

أخطاء جزئية

استخدم return_exceptions=True لمعرفة أي عنصر فشل.

async

في خادم ويب استخدم ainvoke وabatch لعدم حظر الاستجابات.

التوازي الكبير جداً يرفع التكلفة وربما يؤدي لرفض الطلبات — ابدأ بـ 3–5 وجرّب.

سلسلة متفرّعة (Router Chain)

سلسلة واحدة تتفرع إلى مسارات مختلفة حسب نوع السؤال.

router.py
from langchain_core.runnables import (
    RunnableBranch, RunnableLambda
)

def classify(question: str) -> str:
    out = cheap.invoke("صنّف: " + question).content.lower()
    return "code" if "كود" in out or "code" in out else "general"

def prepare(question: str) -> dict:
    return {"type": classify(question), "question": question}

route = RunnableBranch(
    (lambda x: x["type"] == "code", code_chain),
    (lambda x: x["type"] == "docs", rag),
    general_chain,   # الفرع الافتراضي
)

chain = RunnableLambda(prepare) | route
print(chain.invoke("كيف أطبع قائمة في بايثون؟"))

تصنيف رخيص

استخدم نموذجاً صغيراً لتحديد المسار ثم النموذج المناسب للتنفيذ.

RunnableLambda

غلّف أي دالة بايثون عادية لتصبح جزءاً من السلسلة.

فرع افتراضي

دائماً ضع مساراً احتياطياً عند فشل التصنيف.

نشر التطبيق بـ FastAPI

حوّل السلسلة إلى API حقيقي مع بثّ الإجابة للمستخدم.

main.py
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.post("/ask")
async def ask(payload: dict):
    def tokens():
        for piece in chain.stream(
            {"topic": payload["topic"]}
        ):
            yield piece
    return StreamingResponse(
        tokens(), media_type="text/plain"
    )
